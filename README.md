## 📖 About

> **Building systems that institutions can't afford to fail.**

A full-stack portfolio website for **Tesfaye Tilahun** - Systems Engineer based in Addis Abeba, Ethiopia. Features a dynamic portfolio with an admin panel for content management.

### ✨ Key Features

- 📱 Fully responsive design
- 🎨 Modern dark theme
- 🔄 Real-time updates
- 🛠️ Complete admin panel
- 📊 Live statistics dashboard
- 🔍 Filter by category
- 💾 JSON-based storage
- 🚀 Easy deployment
